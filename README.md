# Trickcal One-Cushion

A spoiler cushion for Trickcal players, for X (Twitter) and YouTube. It blurs posts and video thumbnails from the accounts you mark and shows them only when you click. Nothing is removed; you decide whether to look. Interface in English, Japanese and Korean.

- Install: Tampermonkey, then the script from [Greasy Fork](https://greasyfork.org/scripts/597026-trickcal-one-cushion) or the raw file in this repository.
- What it does, how to use it and what data it touches: see [greasyfork-listing.md](greasyfork-listing.md) (English, 日本語, 한국어).
- Tests: `npm install` then `npm test` (jsdom).
